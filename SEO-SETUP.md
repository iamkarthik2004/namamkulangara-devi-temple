# Namamkulangara Devi Temple — SEO launch checklist

## SEO improvements included
- Search-focused page title and meta description.
- Robots directives for Google and other compliant crawlers.
- Canonical URL placeholder.
- Open Graph and X/Twitter sharing metadata.
- JSON-LD structured data describing the website, page and temple location.
- `robots.txt` and `sitemap.xml`.
- More descriptive image alternative text and lazy loading for non-critical images.

## IMPORTANT: complete these before deployment
1. Replace every occurrence of `https://YOUR-DOMAIN` in `index.html`, `robots.txt` and `sitemap.xml` with the exact public website URL, including the correct domain. Do not leave the placeholder in production.
2. Confirm that the temple name, locality, map coordinates and social media URLs in the structured data are correct.
3. Add a real favicon (for example `favicon.ico` and/or PNG icons) and link it in the HTML if the temple has an approved logo.
4. Replace the placeholder phone number, UPI ID, QR image and bank details already documented in the original README. Do not publish placeholder payment details.
5. Add only verified temple timings, pooja names, festival dates, address and contact details. Accurate useful content is more valuable than repeating keywords.
6. Deploy the website over HTTPS and make sure the homepage returns HTTP 200.
7. In Google Search Console, verify the domain, submit `https://YOUR-DOMAIN/sitemap.xml`, and use URL Inspection to request indexing of the homepage.
8. In Google Business Profile, claim or create the temple's official profile if eligible. Keep its name, address, phone, map pin, website and hours consistent with the website.
9. Test the live URL with Google's Rich Results Test and PageSpeed Insights. Structured data does not guarantee a rich result or a ranking.
10. Ask the temple administrators to link to the official website from their verified social profiles and other genuine local/community pages.

## SEO notes
- The site is currently a single-page website. The sitemap therefore contains only the homepage.
- The page uses English as its document language. If a full Malayalam version is published at a separate URL, add a separate Malayalam page and correct `hreflang` annotations for both language versions.
- Search ranking and indexing are controlled by Google; these changes improve crawlability and page understanding but cannot guarantee a first-page result.
